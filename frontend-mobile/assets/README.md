# Assets

Place the following PNG files here before building:

- `icon.png` — 1024x1024 app icon
- `splash.png` — 1242x2436 splash screen (centered logo on dark background `#0F172A`)
- `adaptive-icon.png` — 1024x1024 Android adaptive icon foreground
- `favicon.png` — 48x48 web favicon

Until provided, Expo will use built-in placeholders. The app runs fine without them in development.
